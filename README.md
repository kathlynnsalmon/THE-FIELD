# The Field

**We outgrew the resume. We outgrew the database.**

The Field is a living system for professional identity and people management — built around what people are actually doing, where they're growing, and where they could thrive next. It replaces two things at once: the static resume, and the CRM/database that never really captured the whole person.

## What's in this repo

- `index.html` — the full working prototype. Single-file HTML/CSS/JS, no build step required. Open it directly in a browser.

## What it does

- **For individuals:** turns real project work, leadership, and growth into a living, structured profile — no manual resume writing.
- **For organizations:** one system to recruit, understand, and develop people, built on real signal instead of static titles and keywords.
- Includes a working demo of both experiences — a personal profile/network view and an organization dashboard/recruiting/team view — switchable in one click.

## How to view it

Open `index.html` directly in any modern browser (or visit the GitHub Pages link on this repo's homepage, if enabled). No dependencies, no server required.
